Android

Télécharger l'APK

Télécharger escale.apk Toutes les versions
  1. Ouvre le fichier téléchargé depuis les notifications ou l'appli Fichiers.
  2. La première fois, Android demande d'autoriser l'installation depuis cette source (Chrome ou Fichiers) : accepte.
  3. Pour mettre à jour, télécharge la nouvelle version et installe-la par-dessus : tes voyages restent sur le téléphone.

Play Protect peut afficher « Appli inconnue » : c'est normal pour une maquette qui n'est pas encore sur le Play Store. Choisis Installer quand même.

Web · Android, iPhone, ordinateur

Utiliser la version web

Ouvrir la maquette
  1. Android (Chrome) : menu ⋮ puis « Ajouter à l'écran d'accueil » ou « Installer l'appli ».
  2. iPhone (Safari) : bouton Partager puis « Sur l'écran d'accueil ».
  3. Une fois ouverte une première fois, la maquette fonctionne aussi sans réseau.
